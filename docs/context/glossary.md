# Slovníček

Společné pojmy napříč dokumenty. Pokud starší dokument používá pojem jinak, platí tento slovníček.

| Pojem | Význam | Nezaměňovat s |
|---|---|---|
| **instalace / organizace** (úroveň 1) | Jedno nasazení s vlastní databází: Vonica, nebo Vonička (D-06) | složkou |
| **soubor** | V obecném textu folklorní soubor jako organizace. Ve starších dokumentech (`moje/07`, `08`, `10`, `archive/`) i tenant / `ensemble` | — |
| **člen souboru** (Vonica) | Člen **dospělé složky** Vonice (D-08) | členem Malé Vonice nebo Děvčic |
| **složka** (`Unit`, úroveň 2) | Autonomní část organizace s vlastním vedením, docházkou a krojovým fondem: dospělá Vonica, Malá Vonica, Děvčice, muzika; Vonička I–III | skupinou |
| **skupina** (`Group`) | Organizační nebo komunikační okruh lidí (kluci, holky, Výbor…) | složkou |
| **příslušnost ke složce** (`UnitAffiliation`) | Zájemce / aktivní / bývalý ve složce, s historií | formálním členstvím |
| **formální členství** | Právní členství ve spolku (Vonička; hlasování na členské schůzi) | účastí dítěte v souboru |
| **přijatý člen** | Slavnostní přijetí ve Vonici (rok, kmotr nebo kmotra) | formálním členstvím |
| **osoba** (`Person`) | Evidovaný člověk, i bez účtu a příslušnosti | účtem |
| **účet** (`UserAccount`) | Možnost přihlásit se | osobou |
| **funkce** (`PositionAssignment`) | Organizační pozice s historií; sama nedává přístup | pověřením |
| **pověření** (`Mandate`) | Oprávnění k činnosti v rozsahu soubor / složka / skupina / akce / modul (D-09, D-10) | rolí |
| **externista** | Vztah osoby k činnosti (host, vypůjčitel), ne druh osoby | — |
| **Krojařka** | Aplikace `krojarka.vonica.cz` | krojařkou |
| **krojařka** | Osoba s pověřením ke krojům složky; pomocnice jsou rovnocenné | — |
| **sklad** | Místnost s nezapůjčenými kroji | seznamem součástek |
| **součástka / kus** | Fyzická krojová součást se stabilní identitou | evidenčním číslem |
| **evidenční řada** | Číselná řada kusů dané klasifikace; identifikace = řada + číslo | — |
| **komplet** | Fyzický komplet v obalu s lístkem, s proměnlivým složením (D-19) | šablonou kompletu |
| **krojová karta** | Přehled toho, co má osoba svěřeno | kompletem |
| **výpůjčka** | Svěření kusu (nebo kompletu) držiteli, s historií | — |
| **Správa krojů** | Agenda v budoucí `moje` | aplikací Krojařka |
| **Nepoužívat** | krojárna, krojárka, administrátor (jako role), V1.0 | — |
